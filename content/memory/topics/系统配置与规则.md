# 系统配置与规则

## OpenClaw 配置规则

### 自动保存到 Obsidian

当用户要求保存信息到 Obsidian 时：
1. 提取关键信息
2. 根据内容类型选择目标文件夹
3. 使用合适的模板格式化
4. 保存到 `memory/` 目录

### 内容分类规则

| 内容类型 | 目标文件夹 | 模板 |
|----------|-----------|------|
| 日常想法 | `memory/daily/` | 每日笔记 |
| 学习笔记 | `memory/topics/` | 主题笔记 |
| 项目信息 | `memory/topics/` | 项目笔记 |
| 系统配置 | `memory/topics/` | 配置笔记 |

### 文件命名规范

- 每日笔记：`YYYY-MM-DD.md`
- 主题笔记：`主题名称.md`
- 项目笔记：`项目名称.md`

## 同步规则

- 每日自动同步到 Obsidian
- 重要信息立即保存
- 定期整理和归档
